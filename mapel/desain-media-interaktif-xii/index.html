Minggu 1: Pengenalan Konsep & Klasifikasi Multimedia Interaktif

Periode Belajar: 13 - 19 Juli 2026

Rabu: Teori Kelas (4 JP)

A. Pengertian & Klasifikasi Multimedia

Multimedia terbagi menjadi dua klasifikasi utama berdasarkan tingkat kontrol pengguna:

  • Multimedia Linier: Berjalan satu arah tanpa kontrol navigasi dari pengguna. Alurnya teratur sekuensial dari awal hingga akhir (contoh: Film, TV) [multimodal_4].
  • Multimedia Interaktif: Dilengkapi navigasi yang dioperasikan oleh pengguna secara mandiri untuk mengakses halaman tujuan (contoh: Website, Game) [multimodal_4].

B. Pola Alur Struktur Navigasi

  • Hierarchical (Berjenjang): Pengguna diarahkan melalui menu bercabang yang terstruktur.
  • Non-Linear (Bebas): Pengguna memiliki akses bebas ke seluruh halaman secara acak [multimodal_4].
Koneksi Informatika (Berpikir Komputasional): Penguraian website menjadi halaman-halaman kecil (Dekomposisi) membantu kita merancang alur navigasi yang efisien [passage 117].
Kamis: Praktik Lab (4 JP)

C. LKPD-01: Eksplorasi Navigasi Website Lokal

Tujuan: Siswa mampu mengidentifikasi dan memetakan struktur navigasi web.

Langkah Kerja Lab:

  1. Buka browser dan buka minimal dua website portal berita atau portal pendidikan.
  2. Gambarkan alur menu navigasi dari kedua situs tersebut pada kertas sketsa Anda.
  3. Tentukan apakah situs tersebut menggunakan struktur Hierarchical atau Non-Linear [multimodal_4].
Tugas & Kriteria: Kirim foto sketsa navigasi Anda ke Google Classroom. Penilaian berdasarkan kerapian visual alur menu.

Kuis Mandiri Minggu 1

Pertanyaan: Siaran bioskop / film termasuk dalam kategori multimedia apa?

Minggu 2: Alur Navigasi & Simbol Flowchart Standar

Periode Belajar: 20 - 26 Juli 2026

A. Simbol Flowchart Standar ANSI/ISO

Sebelum mendesain atau mengode, alur navigasi media interaktif harus digambarkan secara logis dengan flowchart menggunakan simbol-simbol standar [passage 290]:

  • Terminator (Oval): Menandai awal (Start) atau akhir (End) sistem [passage 290].
  • Process (Persegi): Menyatakan instruksi internal program [passage 290].
  • Decision (Belah Ketupat): Titik percabangan logika bersyarat [passage 290].
  • Input/Output (Jajaran Genjang): Pengambilan input user atau menampilkan info [passage 290].
Koneksi Informatika (Proses Rekayasa): Pembuatan flowchart alur masuk dalam fase *Analysis & Design* yang krusial sebelum masuk ke tahap pengodean (*Development*) [passage 206].
Kamis: Praktik Lab (4 JP)

B. LKPD-02: Merancang Flowchart Navigasi Profil Diri

Tujuan: Siswa mampu merancang flowchart alur navigasi web portofolio diri.

Langkah Kerja Lab:

  1. Buka komputer lab, akses aplikasi draw.io atau Canva.
  2. Buat flowchart dengan simbol standar yang menunjukkan alur dari halaman *Home* ke halaman *Profil*, *Galeri*, dan *Kuis* [passage 290].
  3. Gunakan simbol Decision untuk menunjukkan logika tombol "Kembali ke Beranda" [passage 290].
Tugas: Ekspor diagram flowchart Anda menjadi PDF/PNG, kumpulkan di folder Google Drive kelas yang disediakan.

Minggu 3: Prinsip Desain User Interface (UI/UX) - Harmony & Proportion

Periode Belajar: 27 Juli - 2 Agustus 2026

Rabu: Teori Kelas (4 JP)

A. Prinsip Desain Antarmuka

Antarmuka media interaktif harus memudahkan pengguna (User Experience) dengan menerapkan prinsip visual [multimodal_10]:

  • Harmony (Keselarasan): Konsistensi gaya grafis, ikon, dan palet warna di semua halaman agar tidak membingungkan [multimodal_10].
  • Proportion (Kesebandingan): Ukuran elemen navigasi disesuaikan dengan bidang kerja [multimodal_10].

B. Ergonomi Tombol Navigasi

Navigasi sentuh membutuhkan ukuran ergonomis agar pas dengan jari manusia [multimodal_10]:

  • Smartphone: Ukuran tombol idealnya berkisar **15-25%** dari luas layar [multimodal_10].
  • Desktop/PC: Ukuran tombol berkisar antara **10-20%** dari bidang layar [multimodal_10].
Kamis: Praktik Lab (4 JP)

C. LKPD-03: Pembuatan Wireframe UI Desktop di Figma

Tujuan: Siswa mampu merancang wireframe layout desktop berdasarkan prinsip proporsi.

Langkah Kerja Lab:

  1. Buka Figma di PC Lab, buat frame desktop (1920x1080px).
  2. Buat wireframe hitam-putih untuk 3 halaman: Beranda, Materi, dan Kuis.
  3. Tempatkan tombol navigasi menu secara konsisten di area kiri atau atas menggunakan ukuran proporsional (10-20%) [multimodal_10].
Tugas: Salin link "Share Viewer" proyek Figma Anda, kumpulkan di Google Classroom.

Minggu 6: Styling Halaman dengan CSS3 - Selector & Box Model

Periode Belajar: 17 - 23 Agustus 2026

Rabu: Teori Kelas (4 JP)

A. Konsep Dasar Cascading Style Sheets (CSS)

CSS berfungsi untuk memperindah tampilan visual halaman HTML yang polos [multimodal_25]. Anatomi penulisan aturan CSS terdiri dari tiga komponen utama [multimodal_25]:

  • Selector: Elemen target HTML yang ingin diubah gayanya (contoh: h1) [multimodal_25].
  • Property: Atribut tampilan yang ingin diganti (contoh: color) [multimodal_25].
  • Value: Nilai perubahan dari atribut tersebut (contoh: blue) [multimodal_25].

B. Penempatan Kode CSS

Aturan style dapat ditaruh lewat 3 cara: Inline style (langsung di tag), Internal style (di dalam tag <style>), atau External style (file terpisah `.css`) [multimodal_25].

Kamis: Praktik Lab (4 JP)

C. LKPD-06: Mengaplikasikan CSS Internal untuk Styling Halaman

Tujuan: Siswa mampu mengganti warna teks, ukuran huruf, dan latar belakang menggunakan CSS.

Langkah Kerja Lab:

  1. Buka file index.html dari tugas minggu lalu di text editor.
  2. Di dalam tag <head>, sisipkan blok tag <style> [multimodal_25].
  3. Gunakan selector untuk mengganti warna font pada heading 1 menjadi merah dan latar belakang bodi menjadi abu-abu terang [multimodal_25, multimodal_28].
Tugas: Kirimkan source code HTML Anda ke form tugas kelas di Google Classroom.

Minggu 7: Layout Web Responsif & Media Queries

Website DMI yang baik harus menyesuaikan tampilannya saat dibuka di komputer desktop, tablet, maupun layar handphone [multimodal_26]. Perbedaan dimensi ini dapat dikelola menggunakan fitur CSS3 Media Queries [multimodal_26].

Media query mendeteksi lebar bidang layar perangkat pengakses lalu menerapkan gaya CSS khusus [multimodal_26]:

Minggu 16: Modular Coding - Fungsi & Parameter

Periode Belajar: 26 Oktober - 1 November 2026

Rabu: Teori Kelas (4 JP)

A. Pemrograman Modular Dengan Fungsi (Function)

Fungsi adalah blok kode terisolasi yang dirancang untuk melaksanakan tugas tertentu secara berulang kali [multimodal_53]. Menulis kode dengan fungsi membuat baris program lebih ringkas dan teratur.

Minggu 17: Debugging & Penanganan Kesalahan Kode

Periode Belajar: 2 - 8 November 2026

Rabu: Teori Kelas (4 JP)

A. Mengatasi Masalah Program (Troubleshooting)

Kesalahan atau galat dalam penulisan baris kode pemrograman merupakan hal yang wajar terjadi [multimodal_51]. Kesalahan penulisan skrip secara garis besar dibagi menjadi tiga kategori utama [multimodal_51]:

  • Syntax Error: Pelanggaran tata bahasa kode (seperti kurang tanda penutup kurung atau titik koma) [multimodal_51, multimodal_52].
  • Logical Error: Program berjalan lancar tanpa eror sistem namun menghasilkan kalkulasi yang keliru karena salah rumus logika.
  • Runtime Error: Terjadi eror saat program dieksekusi di kondisi tertentu (misal memanggil variabel yang belum dibuat).
